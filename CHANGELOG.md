# Changelog

## 0.1.0 — 2026-10-11

First public release of the PlantPal Responsible AI Toolkit.

- Practical guides on plant-care AI risk, privacy and consent, uncertainty, human oversight, fair marketplace recommendations, and higher-risk growing contexts.
- Reusable checklists for evaluation, recommendation review, and agricultural risk.
- Templates for an incident report, a human review record, and a privacy review.
- An educational Python utility that allowlists plant-care context and removes contact, location, and commercial fields, with unit tests and synthetic examples.

This release does not publish a dataset, a model, or PlantPal production code.
